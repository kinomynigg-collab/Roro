# SiteForge — roro (Landing Page)

This is a simple single-page landing site for SiteForge with "roro" included as the owner tag.

Files:
- index.html
- styles.css
- script.js
- README.md

Notes:
- Replace the placeholder email (hello@siteforge.example) in index.html and script.js with your real contact email.
- Portfolio images are placeholders pulled from https://picsum.photos. Replace with your real project screenshots.

Preview locally:
1. Put the files in a directory.
2. Run a simple server from that directory:
   - Python 3: `python -m http.server 8000`
   - Then open http://localhost:8000 in your browser.

Push to GitHub (example commands):
1. git init (if needed)
2. git add .
3. git commit -m "Add SiteForge landing page (roro)"
4. git branch -M siteforge-roro-site
5. git remote add origin git@github.com:kinomynigg-collab/Roro.git
6. git push -u origin siteforge-roro-site

Deploy with GitHub Pages:
- In the repo settings, enable GitHub Pages from the repository branch (e.g., siteforge-roro-site) and the root folder.
